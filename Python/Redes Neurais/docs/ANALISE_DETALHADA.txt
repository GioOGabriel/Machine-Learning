## 🔍 MÉTRICAS EXPLICADAS

### Acurácia
- % de previsões corretas (positivas + negativas)
- **Bom para**: Problemas balanceados

### Precisão
- De todos os Alzheimer previstos, quantos estão corretos
- **Importa**: Evitar alarmes falsos (impacto psicológico)

### Recall (Sensibilidade)
- De todos os Alzheimer reais, quantos foram detectados
- **Crítico**: Não deixar passar casos reais

### F1-Score
- Balanço entre Precisão e Recall
- **Melhor métrica**: Para este problema

### AUC-ROC
- Capacidade de discriminação entre classes
- **Interpreta**: Quanto melhor, melhor a separação
