## 🚀 Como Começar

### Opção 1: Windows (Mais Fácil)
```
Duplo clique em: COMECO_RAPIDO.bat
```

### Opção 2: Terminal
```bash
# Setup
python verificar_projeto.py

# Testar Kaggle
python tests/teste_kaggle.py

# Executar app
python config/launcher_streamlit.py
```

### Opção 3: Streamlit Direto
```bash
streamlit run app_streamlit.py
```
